# Project 1: Configurable ETL

## Objective

Build a configurable ETL pipeline that extracts, transforms, and loads data.

## What is ETL?

ETL stands for:

- **Extract:** Retrieve data from a source.
- **Transform:** Clean, modify, or enrich the extracted data.
- **Load:** Save the transformed data to a destination.

## Concepts Practiced

- Python functions
- Closures
- Configuration-driven programming
- Data transformation
- Record processing
- Modular programming
- Reusable code

## Main File

```text
Configurable ETL/main.py
```

## Run the Program

Open the terminal inside the `Configurable ETL` folder and run:

```bash
python main.py
```

## CSS Box Model

The CSS box model controls the size and spacing of HTML elements.

### Topics Covered

- Content
- Padding
- Border
- Margin
- Element height
- Element width

### Box Model Structure

```text
Margin
┌───────────────────────────┐
│          Border           │
│   ┌───────────────────┐   │
│   │      Padding      │   │
│   │   ┌───────────┐   │   │
│   │   │  Content  │   │   │
│   │   └───────────┘   │   │
│   └───────────────────┘   │
└───────────────────────────┘
```

## CSS Colors

This section covers the different ways to apply colors using CSS.

### Topics Covered

- Named colors
- HEX color values
- RGB color values
- Text colors
- Background colors

### Example

```css
h1 {
    color: blue;
}

body {
    background-color: #f5f5f5;
}
```

## CSS Font Properties

This section focuses on styling text using CSS font properties.

### Topics Covered

- `font-family`
- `font-size`
- `font-weight`
- `font-style`
- `text-align`

### Example

```css
h1 {
    font-family: Arial, sans-serif;
    font-size: 40px;
    font-weight: bold;
    text-align: center;
}
```
