# 🚀 Day 27 - 100 Days of Python Challenge

## 📌 Overview

Day 27 focused on working with two important Python concepts:

1. **Log Analyzer** - File handling and log analysis.

These projects helped strengthen skills in reading and processing files, analyzing large datasets, and creating graphical user interfaces.

# 📂 Project 1: Log Analyzer

## 🎯 Objective

Create a program that reads a log file and analyzes system events to extract useful information.

## 🛠️ Concepts Practiced

- File Handling
- Reading Text Files
- Data Processing
- Log Analysis
- String Operations
- Counting and Filtering Data
- Working with Large Log Files

## 📋 Features

✅ Reads log entries from a file

✅ Counts different log levels (INFO, WARNING, ERROR)

✅ Identifies critical system events

✅ Generates a summary report

✅ Demonstrates processing of large log datasets efficiently

## 📁 Files

```
Log Analyzer/
│
├── main.py
└── system.log
```
