# ✅ Project 1: Attendance System

## 📖 Description

The Attendance System allows users to:

- Mark student attendance
- View attendance records
- Search for a student
- Count attendance records

Attendance information is stored in a text file.

---

## 🚀 Features

✅ Mark Attendance

✅ View Attendance Records

✅ Search Student Attendance

✅ Count Total Records

✅ File Handling

✅ Exception Handling

✅ Menu Driven Program

---

## 📋 Sample Record Format

```text
Rakshith - P
John - A
Mary - P
```

Where:

- **P** = Present
- **A** = Absent

---

## 📌 Menu

```text
========== ATTENDANCE SYSTEM ==========
1. Mark Attendance
2. View Attendance
3. Search Student
4. Count Attendance Records
5. Exit
```
