# 🏓 Pong Game

## 📌 Description

A classic Pong Game built using Python Turtle Graphics and Object-Oriented Programming (OOP).

Players control paddles to prevent the ball from crossing their side of the screen while keeping score.

---

## 🛠 Technologies Used

- Python
- Turtle Graphics
- Object-Oriented Programming (OOP)

---

## 📂 Project Structure

```text
Pong/
│
├── main.py
├── ball.py
├── pad.py
└── score.py
```

---

## 🚀 Features

✅ Two-player gameplay

✅ Paddle movement

✅ Ball movement

✅ Paddle collision detection

✅ Wall collision detection

✅ Score tracking

✅ Ball speed increase after paddle hits

✅ Game reset after scoring

---

## 🧱 OOP Design

### Paddle Class

Responsible for:

- Creating paddles
- Moving paddles up
- Moving paddles down

### Ball Class

Responsible for:

- Creating the ball
- Ball movement
- Wall bouncing
- Paddle bouncing
- Resetting after scoring

### GameScore Class

Responsible for:

- Displaying score
- Updating score
- Keeping track of points
