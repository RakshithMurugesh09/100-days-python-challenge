# Day 17 - Quiz Game (OOP) & User Profile Manager (JSON)

## 📖 Overview

Day 17 consists of two projects that introduce important Python concepts:

- 🎯 **Quiz Game** – Learning Object-Oriented Programming (OOP) using classes and objects.
- 👤 **User Profile Manager** – Learning JSON file handling for storing and managing user data.

---

# 🎯 Project 1: Quiz Game (OOP)

## 📂 Project Structure

```text
Quiz Game/
│
├── data.py
├── main.py
├── question_model.py
└── quiz_brain.py
```

## 📚 Concepts Learned

- Classes and Objects
- Constructors (`__init__`)
- Instance Attributes
- Encapsulation
- Modular Programming
- Object Interaction
- Lists of Objects

## 📄 File Details

### question_model.py
Contains the `Question` class used to create question objects.

### quiz_brain.py
Contains the `QuizBrain` class responsible for:
- Displaying questions
- Checking answers
- Tracking score
- Managing quiz progression

### data.py
Stores all quiz questions and answers.

### main.py
Creates Question objects, initializes the QuizBrain object, and starts the quiz.

## ✅ Features

- Multiple quiz questions
- Score tracking
- Answer validation
- Object-oriented design
- Easy question management

## 🎓 Learning Outcome

Through this project, I learned:

- How to create classes and objects
- How objects interact with each other
- How to organize code using OOP principles
- How to separate data and logic into different modules
- How to build scalable applications using classes

# 👤 Project 2: User Profile Manager (JSON)

## 📂 Project Structure

```text
User Profile Manager/
│
├── main.py
└── profile_manager.py
```

## 📚 Concepts Learned

- JSON Basics
- Reading JSON Files
- Writing JSON Files
- Updating JSON Data
- File Handling
- Exception Handling
- Dictionaries and Lists

## 📄 File Details

### profile_manager.py
Contains functions to:

- Create a profile
- View profile details
- Update profile information
- Manage user skills
- Save data to JSON

### main.py
Provides a menu-driven interface for interacting with profile data.

## ✅ Features

- Create profile
- View stored profile
- Update profile details
- Add skills
- Prevent duplicate skills
- Store data permanently using JSON
- User-friendly menu navigation

## 🎓 Learning Outcome

Through this project, I learned:

- How JSON stores structured data
- How to read data from JSON files
- How to write data to JSON files
- How to update existing JSON records
- How to handle missing files and exceptions
- How to build persistent applications
