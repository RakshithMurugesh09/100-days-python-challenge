## 2. 🎲 Lottery Game

A simple Python Lottery Game built as part of my 100 Days Python Challenge.

### Description

The Lottery Game allows users to enter 6 unique numbers between 1 and 50. The program generates 6 random lottery numbers and compares them with the user's selections to determine the prize.

---

### Features

- User enters 6 unique numbers
- Input validation
- Prevents duplicate numbers
- Generates random lottery numbers
- Displays matched numbers
- Shows total matches
- Prize determination system
- Play again functionality

---

### How It Works

1. Enter 6 unique numbers between 1 and 50.
2. The program generates 6 random lottery numbers.
3. Both sets are compared.
4. Matching numbers are displayed.
5. Prize is awarded based on the number of matches.

---

## Prize Structure

| Matches | Prize |
|----------|--------|
| 3 | 🎉 Consolation Prize |
| 4 | 🥉 Third Prize |
| 5 | 🥈 Second Prize |
| 6 | 🥇 Jackpot |
| Less than 3 | ❌ Better luck next time |
