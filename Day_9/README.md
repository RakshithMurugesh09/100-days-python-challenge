# 🚀 Day 9 - Python Projects

This folder contains three beginner-friendly Python projects created as part of the **💯 100 Days Python Challenge**.

# 📂 Projects Included

## 1️⃣ Blind Auction
A simple console-based blind auction program where users can place bids secretly and the highest bidder wins.

### ✨ Features
- 👥 Multiple bidders support
- 🔒 Secret bidding system
- 🏆 Automatic winner selection

---

## 2️⃣ Contact Book
A basic contact management system that allows users to store and manage contact information.

### ✨ Features
- ➕ Add new contacts
- 📖 View saved contacts
- 🔍 Search contacts
- 💡 Simple and easy-to-use interface

---

## 3️⃣ Student Marks

### ✨ Features
