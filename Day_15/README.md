# 🚀 Day 15 - Python Project Practice

This folder contains two Python projects built to practice different programming concepts and project structures.

---

# Project 1: ☕ Coffee Maker

A console-based Coffee Maker simulation that allows users to order coffee, checks available resources, processes payments, and updates machine resources.

## Concepts Used

- Functions
- Modular Programming
- Dictionaries
- Conditional Statements
- Loops
- Resource Management

## Files

Coffee Maker/
│
├── art.py
├── coffee_data.py
├── coffee_utils.py
└── main.py

## Key Learning

This project focuses on **Modular Programming**, where functionality is split across multiple files. Each file has a specific responsibility, making the code easier to maintain and organize.

---

# Project 2: 🏦 Bank Account Management System

A menu-driven banking application that allows users to create an account, deposit money, withdraw money, check balance, and display account information.

## Concepts Used

- Classes
- Objects
- Constructors (__init__)
- Methods
- Attributes
- Input Validation
- Exception Handling

## Files

Bank Account Management System/
│
├── art.py
├── bankaccount.py
└── main.py

## Key Learning

This project focuses on **Object-Oriented Programming (OOP)**. The `BankAccount` class acts as a blueprint, and each account can be represented as an object with its own data and behavior.
