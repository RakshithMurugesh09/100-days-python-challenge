# 💰 Expense Tracker

## 📖 Overview

The Expense Tracker helps users record and manage daily expenses using an Excel workbook.

The project uses the **OpenPyXL** library to create, read, update, and store expense records directly in an Excel file.

---

## ✨ Features

✅ Create Excel workbook automatically

✅ Add new expenses

✅ View all recorded expenses

✅ Calculate total expenses

✅ Store data permanently in Excel

✅ Input validation

✅ Easy-to-use menu system

---

## 🛠️ Technologies Used

- Python
- OpenPyXL
- Excel (.xlsx)

# 🐍 Snake Game

## 📖 Overview

A classic Snake Game built using Python's **Turtle Graphics** module.

The player controls the snake to eat food, grow longer, and achieve higher scores while avoiding wall collisions.

---

## ✨ Features

✅ Snake movement

✅ Food spawning at random positions

✅ Snake growth after eating food

✅ Live score tracking

✅ Wall collision detection

✅ Game Over functionality

✅ Object-Oriented Programming (OOP)

---

## 📁 Modules

### 🐍 snake.py

Responsible for:

- Creating snake segments
- Snake movement
- Extending snake length
- Direction controls

---

### ⚽ ball.py

Responsible for:

- Creating food
- Random food positioning

---

### 🏆 score.py

Responsible for:

- Displaying score
- Updating score
- Game Over message

---

### 🎮 main.py

Responsible for:

- Game loop
- Collision detection
- Updating screen
- Managing gameplay
