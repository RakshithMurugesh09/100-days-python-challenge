## 2️⃣ Days in Month
A Python program that determines the number of days in a given month and year.

### ✨ Features
- 📅 Month-wise day calculation
- 🌍 Leap year support
- ✅ Accurate results for all months

---

## 3️⃣ Formatted Name
A utility program that formats a user's first and last name into proper title case.

### ✨ Features
- 📝 Accepts user input
- 🔠 Converts names to title case
- 👤 Displays a neatly formatted full name

### 💡 Example

Input:
```text
john
doe
```

Output:
```text
John Doe
```
