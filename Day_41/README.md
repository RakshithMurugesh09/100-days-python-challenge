# 🐍 Python Project

## 📊 Data Quality Log Processor

### Overview

The Data Quality Log Processor analyzes log files and generates reports about data quality issues such as missing values, invalid records, warnings, and errors.

### Features

✅ Read log files

✅ Parse log entries

✅ Count INFO, WARNING, and ERROR records

✅ Detect data quality issues

✅ Generate summary reports

✅ Practice file handling

✅ Use Context Managers

### Concepts Practiced

- File Handling
- Context Managers
- Exception Handling
- String Processing
- Data Validation
- Log Analysis

### Sample Output

```text
===== Data Quality Report =====

Total Records: 100

INFO Logs: 75
WARNING Logs: 15
ERROR Logs: 10

Overall Quality Score: 90%
```
