# Day 18 - Python Challenge

## Overview

Day 18 consists of two mini-projects demonstrating the use of different Python modules:

1. **Spot Painting** 🎨
   - Created using the **Turtle Graphics** module.
   - Inspired by the famous spot painting artwork by **Damien Hirst**.
   - Generates a colorful grid of dots using randomly selected colors.

2. **Validator** ✅
   - Created using Python's **Regular Expressions (`re`)** module.
   - Validates user input such as email addresses, phone numbers, passwords, or other patterns using regex.

---


## Spot Painting Project

### Objective
Create a dot painting using Turtle Graphics by drawing rows and columns of colorful dots.

### Concepts Practiced
- Turtle Graphics
- Functions
- Loops
- Random Module
- Coordinate Positioning

### Features
- Draws a grid of colored dots.
- Uses random colors for each dot.
- Demonstrates graphical programming in Python.

### Module Used

```python
from turtle import Turtle, Screen
import random
```

## Validator Project

### Objective
Validate user inputs using Regular Expressions.

### Concepts Practiced
- Regular Expressions (Regex)
- Pattern Matching
- User Input Validation
- Error Handling

### Features
- Validates user-entered data.
- Uses regex patterns for matching.
- Provides feedback for valid and invalid inputs.

### Module Used

```python
import re
```
