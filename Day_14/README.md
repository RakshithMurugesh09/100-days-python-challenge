# 📅 Day 14 - Python Modules

## 🎯 Goal

Learn how to organize Python projects using modules by splitting code into multiple files instead of writing everything in a single script.

---

# 🚀 Project 1: Age Calculator

A Python application that calculates a user's age based on their birth date.

## 📁 Project Structure

```text
Age Calculator/
│
├── main.py
├── art.py
└── utils.py
```

## ✨ Features

- Accepts user's birth date as input
- Calculates age using the datetime module
- Displays the user's current age
- Uses custom modules for better code organization

## 🛠 Skills Practiced

- Python Modules
- Functions
- Datetime Module
- Import Statements
- Code Reusability
