# Day 16 - Object-Oriented Programming (OOP)

## Overview

Day 16 focused on applying Object-Oriented Programming (OOP) concepts through two hands-on projects:

1. Coffee Maker (OOP Version)
2. Library Management System

These projects helped me understand how classes and objects can be used to create organized, reusable, and scalable Python applications.

---

## What I Learned

### ☕ Coffee Maker Project

The Coffee Maker project helped me learn how multiple classes can work together to achieve a common goal.

Key concepts practiced:

- Creating custom classes and objects
- Using constructors (`__init__`)
- Encapsulation of data and methods
- Object interaction and collaboration
- Organizing code into multiple files
- Building a real-world application using OOP principles

Project Structure:

```text
Coffee Maker/
├── coffeemachine.py
├── data.py
└── main.py
```

---

### 📚 Library Management System

The Library Management System helped me understand how to create and manage multiple objects.

Key concepts practiced:

- Creating multiple Book objects
- Storing objects inside lists
- Managing objects through another class
- Composition (Library contains multiple Book objects)
- Searching and displaying object data
- Object-oriented program design

Project Structure:

```text
Library Management System/
├── book.py
├── library.py
└── main.py
```

---

## OOP Concepts Covered

### ✅ Classes and Objects

Created custom classes to represent real-world entities.

### ✅ Constructors (`__init__`)

Initialized object attributes during object creation.

### ✅ Instance Attributes

Stored data specific to each object.

### ✅ Instance Methods

Created behaviors that belong to objects.

### ✅ Encapsulation

Bundled data and methods together within classes.

### ✅ Composition

Learned how one class can contain and manage objects of another class.

### ✅ Object Collaboration

Used multiple objects that work together to complete tasks.

### ✅ Handling Multiple Objects

Managed several Book objects inside a Library object.

### ✅ Code Organization

Separated logic into different files for better readability and maintainability.
