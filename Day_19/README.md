# 🚀 Day 19 - Python Projects
Welcome to my **Day 19 Python Challenge Projects**! 🎯

This folder contains **three Python projects** that helped me practice **CSV file handling**, **Turtle graphics**, **loops**, **functions**, **exception handling**, and **basic game logic**.

## 📚 Projects Completed
## 1️⃣  Student Marks Manager
The **Student Marks Manager** project is built using Python's `csv` module.

✨This project allows users to:

- Add student names and marks
- Store student records in a CSV file
- View all student records
- Search for a student by name
- Calculate the average marks of all students 

### 📖 Concepts Used
- CSV file handling
- Reading and writing data using `csv.reader()` and `csv.writer()`
- File checking using the `os` module
- Input validation
- Error handling using `try-except`
- Loops and conditional statements

### 📂Files
```text
Student Marks Manager/
├── Student_Marks.csv
└── main.py
```
