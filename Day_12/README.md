# Day 12 - Python Projects

This folder contains two Python projects completed as part of my 
**100 Days of Python Challenge**.

## Projects

### 1. Number Guessing Game

A simple command-line game where the computer randomly 
selects a number between 1 and 100, and the player tries to guess it.

#### Features
- Random number generation
- Easy and Hard difficulty levels
- Limited number of attempts
- High/Low hints after each guess
- Win/Lose conditions

#### Files
- `main.py` - Main game logic
- `art.py` - ASCII art and game banner

#### Concepts Practiced
- Functions
- Conditional statements
- Loops
- User input validation
- Random module

---

### 2. Robust Calculator

A command-line calculator that performs basic arithmetic operations while handling errors gracefully.

#### Features
- Addition
- Subtraction
- Multiplication
- Division
- Custom exception handling
- Input validation
- Division-by-zero handling
- Menu-driven interface

#### Files
- `main.py` - Calculator implementation

#### Concepts Practiced
- Functions
- Custom Exceptions
- Try/Except blocks
- Input validation
- Loops and program control

---

## Learning Outcomes

By completing these projects, I practiced:

- Writing reusable functions
- Error and exception handling
- Validating user input
- Building interactive console applications
- Organizing Python projects
- Debugging and troubleshooting code
